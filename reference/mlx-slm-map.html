How classification meets an SLM

Target tokens = closed label string. Prefer chat/completions JSONL + prompt masking so loss sits on the label.

{"messages":[
  {"role":"user","content":"Classify…\nText: UPI-AMZN… Rs.1249"},
  {"role":"assistant","content":"shopping"}
]}

Draft label seeds (not legal advice)

Will be frozen in a dedicated reference when schema is locked.

  • shopping · interest_income · dividend · salary
  • transfer · tax_payment · investment · other

Hardware (locked)

  • Apple M2 Pro · 32 GB unified memory · macOS ≥ 14 · native Python ≥ 3.10
  • Default labs: ~0.5B–3B instruct (often 4-bit). 7B QLoRA later with memory knobs if needed
  • Course files may be edited on another machine — MLX train/infer still runs on the Mac
  • Memory tips: smaller model, 4-bit base (QLoRA), --batch-size 1, fewer --num-layers, --grad-checkpoint — see LORA.md Memory Issues

Core commands (cheat)

pip install "mlx-lm[train]"

mlx_lm.generate --model <mlx-model> --prompt "…"

mlx_lm.lora --model <mlx-model> --train --data ./data --iters 600

mlx_lm.fuse --model <mlx-model> --adapter-path ./adapters
