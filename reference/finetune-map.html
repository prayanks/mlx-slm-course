Fine-tune map at a glance

Compressed compass. This course is supervised fine-tuning for transaction→label — not pretraining, not “build an SLM” as a separate category.

What we are doing

pretrained open instruct model
  + JSONL demos (transaction text → label)
  + mlx_lm.lora (LoRA / QLoRA)
  + held-out classifier metrics
  + optional mlx_lm.fuse
= fine-tuned txn labeler on your Mac

What we are not doing

  • Pretraining a transformer from random weights
  • Branding the course as “SLM” when the skill is fine-tuning
  • Cloud-prompt only (skips the Mac fine-tune craft)
  • Free-form tax essays as training targets
  • Confusing our labels with §285BA reporting tables

Fine-tune data shape

{"messages":[
  {"role":"user","content":"Classify…\nText: UPI-AMZN… Rs.1249"},
  {"role":"assistant","content":"shopping"}
]}

Prefer chat/completions + prompt masking so loss sits on the label. See LORA.md Data section.

Draft labels (not legal advice)

  • shopping · interest_income · dividend · salary
  • transfer · tax_payment · investment · other

Hardware (locked)

  • Apple M2 Pro · 32 GB · macOS ≥ 14 · native Python ≥ 3.10
  • Default fine-tune bases: ~0.5B–3B instruct (often 4-bit)
  • Memory knobs: batch size 1, fewer LoRA layers, grad checkpoint — LORA.md Memory Issues

Core commands

pip install "mlx-lm[train]"

mlx_lm.generate --model <mlx-model> --prompt "…"

mlx_lm.lora --model <mlx-model> --train --data ./data --iters 600

mlx_lm.fuse --model <mlx-model> --adapter-path ./adapters
